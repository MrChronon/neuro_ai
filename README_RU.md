# neuro_ai

Учебно-исследовательский проект по нейровизуализации, computational cognitive science, computational neuroscience и NeuroAI.

Проект начинается с реальных мультимодальных нейровизуализационных данных University of Cambridge / MRC Cognition and Brain Sciences Unit и постепенно движется от понимания эксперимента и структуры BIDS к анализу fMRI, EEG/MEG, машинному обучению, мультимодальному анализу и NeuroAI.

## Текущий этап

**Этап 1: основы нейровизуализации**

Основной датасет: **Wakeman & Henson multimodal neuroimaging dataset, OpenNeuro ds000117**.

Первая практическая контрольная точка уже в значительной степени закрыта. На реальных данных `sub-01` мы:

- загрузили BOLD NIfTI через NiBabel;
- посмотрели реальный 4D shape `(64, 64, 33, 208)`;
- получили voxel size и TR `(3.0, 3.0, 3.75, 2.0)`;
- извлекли и визуализировали sagittal, coronal и axial срезы реального fMRI volume;
- загрузили structural T1w MRI того же участника `(192, 256, 256)` с изотропными voxel `1 мм`;
- сравнили пространственное разрешение T1w MRI и BOLD fMRI;
- посмотрели реальные affine-матрицы обоих изображений.

Текущая тема: **voxel coordinates → affine → world coordinates → пространственное соответствие fMRI и T1w**.

После завершения пространственных основ следующий аналитический блок:

`events → HRF → design matrix → GLM`.

## Принцип обучения

Эксперимент → данные → статистика → fMRI → ML → EEG/MEG → мультимодальный анализ → NeuroAI.

Сложные методы добавляются только после понимания данных и предпосылок.

## Структура репозитория

- `notebooks/` — учебные и исследовательские ноутбуки
- `src/` — переиспользуемый Python-код
- `tests/` — тесты для переиспользуемого кода
- `configs/` — конфигурационные файлы проекта
- `docs/` — учебные главы, документация и методические заметки
- `figures/` — концептуальные учебные схемы и визуализации реальных данных
- `results/` — производные численные результаты
- `reports/` — исследовательские отчёты и черновики
- `references/` — заметки по статьям, датасетам и источникам
- `data/` — локальные нейроданные; raw data в Git не загружаются
